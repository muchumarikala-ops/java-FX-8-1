# Problem 2: JavaFX Label and ImageView

## Aim
To create a GUI using JavaFX that displays text in a Label and an image in an ImageView without writing Java code for the GUI layout.

## Components Used
- Label
- ImageView
- VBox
- Scene Builder
- FXML

## Description
The Label component displays the text "Welcome to JavaFX!". The ImageView component displays an image. The GUI layout is designed using JavaFX Scene Builder and saved as an FXML file.

## Files Used
- MainApp.java
- sample.fxml
- sample.png

## Procedure
1. Create a JavaFX project.
2. Design the GUI using Scene Builder.
3. Add a Label to display text.
4. Add an ImageView to display an image.
5. Save the layout as sample.fxml.
6. Run the application.

## Result
Successfully created a JavaFX GUI displaying text using a Label and an image using an ImageView.
